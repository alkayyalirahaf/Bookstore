# Bookstore & Reading Club

A web application created as part of the Web Development Bootcamp assignments. It provides a simple interactive experience for a community bookstore, allowing users to register, pick categories, and reserve books.

## 🛠️ Project Structure & Technologies
- **HTML5:** Page structure and content semantics.
- **CSS3:** Custom styles, Flexbox layout, CSS variables, and clean UI styling.
- **JavaScript (JS):** Dynamic user interaction using `prompt()`, `alert()`, `console.log()`, and `if-else` condition logic.
